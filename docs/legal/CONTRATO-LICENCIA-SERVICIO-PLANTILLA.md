### 4. Alcance de la licencia

La licencia otorgada al Cliente es:

- **No exclusiva** — el Proveedor puede licenciar el mismo Software a

- **Intransferible** — el Cliente no puede cederla, venderla ni
  compartirla con un tercero sin autorización escrita del Proveedor.
- **Limitada al uso interno** del Cliente, para administrar su propio
  inventario, mantenimiento y soporte técnico — no para reventa,
  sublicencia, ni para ofrecer el Software como servicio a terceros.

**El Cliente NO puede:**
- Copiar, distribuir o revender el Software, total o parcialmente.
- Realizar ingeniería inversa del código, salvo lo estrictamente
  necesario para la interoperabilidad y en la medida que la ley lo
  permita de forma imperativa.
- Usar el Software, su código o su diseño como base para desarrollar un
  producto competidor.
- Eliminar o alterar avisos de propiedad o autoría dentro del código o
  la documentación.
